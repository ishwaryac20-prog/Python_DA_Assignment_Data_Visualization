# 🚕 Python DA Assignment – Data Visualization

## 📌 Project Overview

This project focuses on **data cleaning, exploratory data analysis, and data visualization** using the Seaborn `taxis` dataset.

The objective is to analyze taxi trip data and understand patterns related to **fare, distance, tips, payment methods, pickup boroughs, and pickup zones** using Python visualization libraries.

## 🎯 Objectives

- Load and inspect the `taxis` dataset
- Identify and handle missing values
- Analyze taxi fare and trip-distance patterns
- Explore payment-method distribution
- Compare trip and fare patterns across pickup boroughs
- Study relationships between numerical variables
- Create meaningful visualizations using **Matplotlib, Pandas, and Seaborn**

## 🛠️ Technologies & Libraries

- 🐍 Python
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib
- 🎨 Seaborn
- 📓 Google Colab / Jupyter Notebook

## 🧹 Data Cleaning

The project includes:

- Missing-value identification
- Median imputation for numerical columns
- Mode imputation for categorical columns
- Conversion of the `pickup` column into datetime format
- Removal of rows where the pickup timestamp could not be reasonably used

## 📊 Visualizations

### Matplotlib / Pandas

1. 📈 **Line Chart** – Average fare over time
2. 📊 **Bar Chart** – Total fare by pickup borough
3. 🥧 **Pie Chart** – Trip distribution by payment method
4. 📏 **Histogram** – Distribution of trip distance

### Seaborn

5. 📦 **Box Plot** – Tip distribution by pickup borough
6. 🔢 **Count Plot** – Number of trips by pickup borough
7. 🔵 **Scatter Plot** – Relationship between distance and fare
8. 🔥 **Heatmap** – Correlation between distance, fare, tip, tolls, and total
9. 🔗 **Pair Plot** – Relationships between distance, fare, tip, and total by pickup zone
10. 🎻 **Violin Plot** – Fare distribution by payment method

## 🔍 Key Analysis

The project examines:

- Fare trends over time
- Pickup-borough contribution to total fare
- Most frequently used payment methods
- Distribution of trip distances
- Tip patterns across boroughs
- Trip volume across pickup boroughs
- Relationship between distance and fare
- Correlation among important numerical variables
- Differences between pickup zones
- Fare distribution across payment methods

This project demonstrates how Python can be used to transform raw taxi trip data into meaningful visual insights. The combination of **Pandas, Matplotlib, and Seaborn** makes it possible to explore trends, distributions, relationships, and patterns within the dataset.
